PRINCE INVITATIONS — PHOTO GALLERY

Upload wedding photos into this folder. They appear automatically in the Photo Gallery tab after the GitHub Pages deployment is complete and the page is refreshed.

Use these filenames in sequence (up to 24 photos):
  photo-01.jpg
  photo-02.jpg
  photo-03.jpg
  ...
  photo-24.jpg

Supported extensions: .jpg, .jpeg, .png, .webp, .avif
Example: photo-01.png is also supported.

Important:
1. Upload the image files to this exact assets/photos/ folder in the GitHub repository.
2. Commit the uploaded photos. GitHub Pages must finish publishing before visitors can see them.
3. Refresh the invitation page.
4. Keep the sequence numbers; missing numbers are okay.
5. For best quality and fast loading, use clear images around 1600px on the long edge and preferably under 2 MB each.

This website is static. Guests cannot upload photos from the public invitation page; photos are added by the site owner through the project/repository.
